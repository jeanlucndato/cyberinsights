🐝 Hive — Observe.
Investigate. Learn.

Hive turns activity against decoy services into a live, searchable security investigation workflow. Four protocol-aware Go sensors feed a React and TypeScript console, with STIX 2.1 exports and firewall suggestions for operator review.

Architecture & event flow

From decoy interaction to investigation

Protocol-specific sensors normalize observations into one event pipeline. Bounded fan-out keeps slow dashboard clients from blocking sensors, while the local journal preserves searchable history.

Protocol-aware sensors

SSH presents a simulated shell; HTTP serves a decoy site; MySQL parses a bounded handshake and returns access denied; Redis handles a limited set of inline and RESP commands.

Shared event pipeline

Typed events receive IDs and sensor IDs, heuristic MITRE ATT&CK tags, in-memory retention, rotating JSONL journal records, and delivery through bounded subscriber queues.

Operator console

The React and TypeScript dashboard combines journal search with a reconnecting WebSocket stream. Operators can filter events, inspect details, view health metrics, and export filtered results to CSV.

Reviewable intelligence

Valid source IP observations are deduplicated for STIX 2.1 indicators and suggested firewall commands. Suggestions are for human review and are never applied automatically.

Responsible deployment

Decoys belong in an isolated lab

Hive is for controlled monitoring and experimentation, not a production server or turnkey SOC platform. The SSH shell never executes host commands. Protocol emulations are limited, and ATT&CK tags are heuristic leads, not proof of malicious activity.

  • All listeners default to 127.0.0.1.
  • Non-loopback API binds require a bearer token; keep the dashboard API private.
  • Captured attacker-supplied data may still be sensitive; redaction is best effort.
  • Inspect firewall suggestions manually. Never pipe the generated file into a shell.
  • Use a dedicated isolated host with no production credentials before exposing decoys.

Local walkthrough

With Go 1.26.4+ and Node.js 20.19+ or 22.12+, run from the repository root:

./run-local.sh

Open http://127.0.0.1:5173 and select Decoy website. Generate sample activity:

curl http://127.0.0.1:8080/wp-login.php
ssh -p 2222 root@127.0.0.1

Dashboard: 5173; HTTP decoy: 8080; API/health: 8000; SSH, MySQL, Redis: 2222, 3306, 6379.

Scope & next steps

Built for controlled experimentation

Hive uses bounded rotating JSONL files rather than an indexed database. Protocol emulations are deliberately narrow, ATT&CK correlations are heuristic, and GeoIP enrichment is not included. Larger captures would benefit from indexed storage, richer sensor administration, and configurable threat-intelligence enrichment.
